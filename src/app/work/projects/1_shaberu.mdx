## Overview

Shaberu is an AI-powered platform that converts any video URL into an accurate, word-timed transcript and layers a structured language-learning experience on top of it. Paste a YouTube link, and the app downloads the audio, transcribes it with word-level timestamps, and makes the transcript translatable into 50+ languages. Learners can follow along with the video, and Japanese transcripts get inline furigana readings generated by a morphological tokenizer.

A separate learning module offers structured JLPT-style grammar, vocabulary, kanji, and conversation content (N5–N3) independent of any video, making the product both a transcription utility and a complete study environment.

As the full-stack developer for this project, I owned the entire product end to end: the background transcription pipeline, the translation layer, the Supabase data model, authentication, subscription billing, and the complete user interface.

## Development Role

### Responsibilities
- **Background Pipeline Architecture**: Designed the download → transcribe → preprocess → translate pipeline using Next.js `after()` so long-running jobs survive serverless response cycles without a separate worker service
- **Multi-Provider AI Integration**: Abstracted Speechmatics, OpenAI Whisper, and AssemblyAI behind a single pluggable transcription interface
- **Data & Storage Layer**: Modeled job state in Supabase Postgres and cached transcripts/translations as JSON in Supabase Storage
- **Authentication & Billing**: Supabase Auth (email/password + OAuth) with Polar subscriptions gating duration limits, translation languages, and exports per tier
- **Frontend Implementation**: Built the video player experience, transcript reader, marketing site, and the standalone Japanese learning module
- **Infrastructure**: Cloudflare Worker proxy in front of audio downloads, Vercel serverless deployment, and fail-fast environment validation

### Technical Stack
- **Next.js 15 (App Router)**: Server-side rendering, route groups, and API routes
- **React 19 + TypeScript**: Type-safe component architecture across both product areas
- **Tailwind CSS 4**: Utility-first styling with dark/light theming
- **Supabase**: Postgres, Storage, and Auth (server + browser clients)
- **Speechmatics / OpenAI Whisper / AssemblyAI**: Pluggable speech-to-text providers
- **OpenAI (GPT-4.1-nano)**: On-demand transcript translation
- **Kuromoji tokenizer**: Japanese morphological analysis for furigana annotation
- **Polar**: Subscription billing and checkout
- **p-queue**: In-process concurrency throttling for expensive pipeline steps
- **Winston**: Structured logging with serverless-safe console transport

## Key Features

### Transcription Pipeline
- **Any Video URL**: Submit a link and the platform resolves the source, checks for an existing job, and kicks off processing
- **Word-Level Timestamps**: Transcripts are aligned to the video for precise follow-along
- **Resumable Job State**: Progress lives in a `video_status` row with staleness detection, so a crashed job never wedges future requests
- **Multi-Provider Support**: Switch transcription engines per request behind a single `model` argument

### Translation Layer
- **50+ Target Languages**: On-demand translation of the preprocessed transcript
- **Cached Per Language**: Each translation is stored as its own file — a video is transcribed once and translated lazily, forever
- **LLM-Powered**: GPT-4.1-nano produces natural translations of grouped, readable chunks

### Language Learning
- **Inline Furigana**: Japanese transcripts annotated with readings via a kuromoji-based tokenizer during preprocessing
- **JLPT Module**: Standalone `/learn/japanese` experience with structured grammar, vocabulary, kanji, and conversation content (N5–N3)
- **In-Context Lesson Viewer**: Parallel/intercepting routes (`@modal`) open lessons without losing the learner's place

### Product & Monetization
- **Tiered Plans**: Free / Basic / Advanced gate max video duration (5 min → 2 hrs), allowed translation languages, and export access
- **Auth Flows**: Email/password and OAuth under a unified session model
- **Marketing Site + Account Management**: Landing, pricing, billing, and account pages in the same app
